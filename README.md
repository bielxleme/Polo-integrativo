# Polo Veterinário Integrativo Gabriella Radavelli — Landing Page

Landing Page institucional de alto padrão desenvolvida com **Vite + React + Tailwind CSS**, pronta para deploy imediato na **Vercel**.

## Estrutura do Projeto

- `public/logo-gr.jpg`: Logotipo oficial do Polo Veterinário Integrativo Gabriella Radavelli.
- `src/config/siteConfig.js`: Arquivo centralizador com todas as informações de contato, links do WhatsApp, Instagram e caminhos de imagens.
- `src/components/`: Componentes modulares da página (`Header`, `Hero`, `BentoPillars`, `AboutDoctor`, `Testimonials`, `ContactLocation`, `Footer`, `FloatingWhatsApp`).

## Como rodar localmente

```bash
npm install
npm run dev
```

## Como subir para o GitHub e publicar na Vercel

1. Extraia o conteúdo deste arquivo `.zip`.
2. Suba os arquivos para um novo repositório no seu GitHub.
3. Acesse a [Vercel](https://vercel.com/), clique em **Add New... -> Project** e importe o repositório.
4. O preset **Vite** será detectado automaticamente (`npm run build` / diretório `dist`). Basta clicar em **Deploy**!
